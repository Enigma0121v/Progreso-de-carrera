## Notas y faltantes
- `Correlativas Ing. Electronica.pdf` es en realidad la Res. FRH 324/2023 (3 páginas, distribución de
  materias entre planes P95 y P2003). Casi no trae correlatividades: verificar si el régimen completo
  está en el plan (Ord. 1849) o si falta el documento específico de correlativas.
- Correlativas originales de Bioingeniería: el archivo disponible es solo la modificación (CSU 2131).

Datos útiles por materia: año, nombre, carga horaria, correlativas para cursar
(regularizada/aprobada), correlativas para rendir y horas de electivas.
