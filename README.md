# Agenda Virtual de la UTN (FRH)

Seguimiento de carrera para las 6 ingenierías de la UTN Facultad Regional Haedo (Plan 2023):
materias regulares y aprobadas, qué podés cursar y qué finales podés rendir según las correlativas,
notas con promedio y horas de electivas. Con cuenta (mail + contraseña) el progreso se sincroniza
entre dispositivos.

Proyecto independiente, sin vínculo oficial con la UTN. Datos orientativos, no oficiales.

- Cómo configurarla y publicarla: [`docs/CONFIGURAR.md`](docs/CONFIGURAR.md)
- Dudas sobre los datos de los planes: [`docs/DUDAS-DATOS.md`](docs/DUDAS-DATOS.md)
